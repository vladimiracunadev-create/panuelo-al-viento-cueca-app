# Guía breve para docentes y familias

## Antes de abrir la aplicación

- Define un espacio seguro y una señal de pausa.
- Pregunta qué conoce el niño y evita asumir que parte desde cero.
- Ten un pañuelo liviano; no se necesita vestimenta especial.
- Selecciona música autorizada solo cuando la clase lo indique.

## Durante una clase

La persona adulta demuestra una vez, permite explorar y pregunta qué sintió el niño. Corrige una sola cosa cada vez. Si el niño propone una alternativa segura, úsala como evidencia de comprensión.

Frases útiles:

- “Muéstrame dónde empieza y termina tu recorrido”.
- “¿Qué señal podemos usar para detenernos?”.
- “¿Qué cambió entre los dos intentos?”.
- “Hazlo más pequeño para que siga siendo cómodo”.
- “No salió todavía; ¿qué información nos dio?”.

Evita:

- “Así no bailan los hombres/las mujeres”.
- “El que zapatea más fuerte gana”.
- “Todos deben hacerlo idéntico”.
- tocar o mover el cuerpo del niño sin pedir permiso;
- grabar por defecto;
- usar la presentación pública como amenaza o premio.

## Sesión ampliada de 45 minutos

| Minutos | Actividad |
|---:|---|
| 0–5 | Bienvenida, experiencia previa y seguridad. |
| 5–10 | Activación corporal y pulso. |
| 10–22 | Una clase de la aplicación. |
| 22–32 | Práctica en estaciones o parejas. |
| 32–38 | Variación creativa o vínculo con música/historia. |
| 38–43 | Presentación voluntaria en grupo pequeño. |
| 43–45 | Reflexión y próximo foco. |

## Evidencia mínima

Registra fecha, clase, adaptación usada, algo que funcionó y próximo foco. No necesitas grabar video ni identificar públicamente al niño.
