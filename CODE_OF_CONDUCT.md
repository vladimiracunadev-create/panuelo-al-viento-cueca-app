# Código de conducta

Este proyecto debe ser un espacio respetuoso para comunidades, cultores, docentes, familias y desarrolladores.

No se toleran burlas por habilidad corporal, identidad, origen territorial, vestimenta, discapacidad o forma de bailar. Las diferencias entre variantes de cueca se documentan con curiosidad y sin establecer jerarquías culturales.

Quien mantenga el proyecto puede moderar o retirar contenido que contradiga estos principios.
